## 模板 1：`axes_plot`（函数图像 / 交点 / 单调性）

### A1. 三次函数的单调性与极值 ★未跑

求 f(x) = x³ - 3x 的单调区间与极值。

- 预期分镜：`title_card` → `axes_plot`（单函数）→ `step_card`（求导 f'(x)=3x²-3，令其=0 得 x=±1）→ `summary_card`
- 关键参数：`expr="x**3 - 3*x"`，`x_range=[-2.5, 2.5, 1]`，`y_range=[-4, 4, 1]`
- 期望答案：增区间 (-∞,-1)∪(1,+∞)，减区间 (-1,1)；极大值 f(-1)=2，极小值 f(1)=-2

### A2. 两曲线交点个数 ★未跑

判断方程 eˣ = x + 2 的实根个数。

- 预期分镜：`title_card` → `axes_plot`（**两函数**，`e**x` 与 `x+2`）→ `step_card` → `summary_card`
- 关键参数：`functions=[{expr:"e**x", color:"BLUE"}, {expr:"x+2", color:"YELLOW"}]`
- 期望答案：2 个实根（x≈-1.84 与 x≈1.15）
- **测什么**：`axes_plot` 多函数模式下图例是否清晰、两曲线是否可区分

### A3. 闭区间最值 ★未跑

求 f(x) = x² - 2x - 3 在 [-1, 3] 上的最大值与最小值。

- 关键参数：`expr="x**2 - 2*x - 3"`，`x_range=[-2, 4, 1]`，`y_range=[-5, 6, 1]`
- 期望答案：最小值 f(1) = -4，最大值 f(-1) = f(3) = 0
- **测什么**：顶点落在区间内时画面是否居中合理

## 模板 2：`function_transform`（平移 / 缩放 / 翻折）

### B1. 二次函数的复合变换 ★未跑

由 y = x² 经过怎样的变换得到 y = 2(x-1)² + 3？

- 关键参数：`from_expr="x**2"`，`to_expr="2*(x-1)**2 + 3"`
- 期望答案：右移 1 → 纵向拉伸 2 倍 → 上移 3
- **测什么**：`to_label` 含复杂括号时 MathTex 能否正确渲染

### B2. 三角函数的相位变换 ★未跑

由 y = sin x 变换到 y = 3sin(2x + π/4)。

- 关键参数：`from_expr="sin(x)"`，`to_expr="3*sin(2*x + pi/4)"`
- 期望答案：横向压缩为 1/2 → 左移 π/8 → 纵向拉伸 3 倍
- **测什么**：周期变密时采样点够不够（曲线是否失真）

### B3. 翻折 + 平移 ★未跑

由 y = 2ˣ 变换到 y = 2^(-x+1) - 1。

- 关键参数：`from_expr="e**x"`（⚠️ 当前求值器**不支持 `2**x` 底数写法**吗？需实测）→ 若不支持改用 `exp(x)` 与 `exp(-x+1) - 1`
- 期望答案：关于 y 轴翻折 → 右移 1 → 下移 1
- **测什么**：衰减函数（趋近 y=-1 渐近线）时 y_range 是否合理

## 模板 3：`taylor_approx`（极限 / 泰勒展开）

### C1. 对数与三角混合求极限 ✅已验证

求 lim(x→0) [ln(1+x) - sin x + x²/2] / x³

- 文件：`examples/lim_taylor.json`
- 期望答案：**1/2**
- 推导：(x - x²/2 + x³/3) - (x - x³/6) + x²/2 = **x³/2**，除以 x³ 得 1/2
- **已发现 bug**：① 无图例（已修）② summary 与 step 重叠（已修，架构层清屏）

### C2. 指数函数的二阶极限 ★未跑

求 lim(x→0) (eˣ - 1 - x) / x²

- 关键参数：`target_expr="exp(x) - 1"`，`terms=["x", "x**2/2"]`
- 期望答案：**1/2**
- 推导：eˣ = 1 + x + x²/2 + o(x²)，故 eˣ - 1 - x = x²/2

### C3. 三角函数三阶极限 ★未跑

求 lim(x→0) (tan x - sin x) / x³

- 关键参数：`target_expr="sin(x)/cos(x) - sin(x)"`（⚠️ 需确认 `_check_expr` 允许 `/`）→ 备选 `target_expr="sin(x)"` + 单独算 tan
- 期望答案：**1/2**
- 推导：tan x - sin x = (x + x³/3) - (x - x³/6) = x³/2

## 模板 4：`area_under_curve`（定积分 / 曲边梯形）

### D1. 区间再现换元 ✅已验证

### D2. 最简单的幂函数面积 ★未跑

- 期望答案：**1/3**
- **测什么**：面积填充区域很小时是否还看得见

## 模板 5：`step_card`（任意推导过程 · 万能件）

> 这个模板几乎每题都要用，所以它的测试题是**纯推导题**（不需要图形）。

### E1. 数学归纳法 ★未跑

用数学归纳法证明 1 + 2 + … + n = n(n+1)/2

- 期望步骤：① n=1 成立 ② 假设 n=k 成立 ③ 推 n=k+1 ④ 综上
- **测什么**：4 步纯文字（**无 formula_latex**）时槽位高度 0.85 是否够、是否偏空

### E2. 乘积求导 ★未跑

求 d/dx [x² · ln x]

- 期望步骤：① 用乘积法则 ② (x²)'·ln x + x²·(ln x)' ③ = 2x·ln x + x ④ = x(2ln x + 1)
- 期望答案：**x(2ln x + 1)**
- **测什么**：`ln` 在 LaTeX 里应写作 `\ln`，检查公式是否美观

### E3. 一元二次不等式 ★未跑

解不等式 x² - 5x + 6 < 0

- 期望步骤：① 因式分解 (x-2)(x-3) < 0 ② 零点 x=2, x=3 ③ 开口向上取中间 ④ 解集 2 < x < 3
- 期望答案：**(2, 3)**
- **测什么**：纯文字 + 短公式混排
